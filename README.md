# PCOMVP — Releases

Download builds of **PCOMVP**, a free desktop app that imports giving data —
donations, notes and pledges — from CSV files into
[Planning Center Online](https://www.planningcenter.com/).

## Download

Grab the newest build from the [**Releases**](../../releases/latest) page:

| Platform | File |
|----------|------|
| macOS    | `pcomvp-desktop-<version>-mac-x64.dmg` |
| Windows  | `pcomvp-desktop-<version>-win-x64.exe` |

Once installed, the app checks this repository for updates on its own — you
should not need to come back here.

## What this repository is

Distribution only. It holds the signed installers and the `latest.yml` /
`latest-mac.yml` manifests the in-app updater reads. There is no source code
here, and issues filed against this repository are not monitored.
